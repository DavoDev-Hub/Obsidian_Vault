# Bases de datos NoSQL

*Origen*
Empezaron con el desarrollo tanto Google como Amazon con las soluciones Big Tables y DynamoDB respectivamente. Estas soluciones permiten el almacenamiento de grandes volúmenes de datos en ambientes distribuidos, dando origen a las primeras bases de datos NoSQL.

Muchas empresas al ver el éxito que estaban teniendo empezaron a diseñar sus aplicaciones para hacer un uso similar con este tipo de bases de datos, si bien no tenían la gran cantidad de datos como Google o Amazon, pero viendo las ventajas que ofrecían empezaron con la migración.

Hoy en dia existen varios sistemas de bases de datos no relacionales, siendo MongoDB un sistema representativo de este tipo de bases de datos.

##### Ventajas de una base de datos NoSQL
*Productividad del desarrollo de aplicaciones*
En el desarrollo de aplicaciones con bases de datos relacionales, se tiene que mapear las estructuras de datos con las que se utilizan en memoria, esto lleva tiempo y gran esfuerzo cuando las bases de datos son compleajas.

Un sistema de bases de datos NoSQL proporciona un modelo de datos que encaja con las necesidades de las aplicaciones, lo que conlleva en codificar, depurar y evolucionar más las aplicaciones.

*Datos a gran escala*
Hoy en días, empresas han encontrado muy valiosa la posibilidad de tener muchos datos y procesarlos rápidamente. En general con una base de datos relacional es caro, por lo que requiere mucha inversion en servidores.

Las bases de datos NoSQL están diseñadas para ejecutarse sobre clústeres, es decir que puedes tener muchas maquinas pequeñas (o bajo costo ejecutando instancias de estas bases de datos)

##### Características de las bases de datos NoSQL

* No utilizan SQL como lenguaje de consulta, sin embargo algunas de ellas utilizan un lenguaje de consultas similares a SQL tales como CQL en Cassandra.
* En general se tratan de proyectos de código abierto
* Muchas de estas bases de datos nacieron para ejecutarse sobre clústeres, lo que ha influido en su modelo de datos
* Las bases de datos NoSQL no tienen un esquema fijo.
