# Modelos de bases de datos NoSQL

Resulta complicado realizar una categorización de las bases de datos NoSQL, sin embargo de acuerdo con el modelo de datos podemos distinguir:
* Clave valor: Riak, Redis, Dynamo, Voldemort
* Orientadas a documentos: MongoDB, CouchDB
* Basadas en columnas: Cassandra, HyperTable, HBase, SimpleDB
* Grafos: Neo4J, Infinite Graph
